A small GPT,
no libraries, no shortcuts.

Tokenizer, multi-head causal attention, the backward pass, Adam, the whole training loop - written by hand in Java and trained on real encyclopedia text. The trained weights ship as a file, and a matching engine in JavaScript runs the same network right here in your tab.
